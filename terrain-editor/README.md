# 机器人野外测试场 · 测试路面与障碍过程式生成编辑器

Vue 3 + WebGPU 实现的过程式地形生成平台。一片场地固定 **40m × 40m**，切成 **8 × 8 = 64 个区块**（每块 5m），
网格分辨率 **257 × 257**（格距 0.15625m，共 131,072 个三角面）。

## 启动

```bash
npm install
npm run dev        # http://127.0.0.1:5180
npm run build      # 生产构建
npm run test:core  # 引擎核心单测（24 项，纯 Node，无需浏览器）
```

> WebGPU 需 Chrome/Edge 113+。浏览器不支持时画布显示降级提示，地形引擎、质检与导出仍可独立运行。

## 四个界面

| 界面 | 能力 |
| --- | --- |
| **需求单** | 前台建单（标题、客户、需求描述、seed、五参数），按建模员分配，状态流转 |
| **生成编辑** | 参数滑杆增量生成、框选锁定/解锁、刷高/削平/挖沟、实体/线框切换、区块实时信息、导出与提交质检 |
| **质检** | 拿同一 seed + 同参数全新重跑，比对高度指纹；一致通过归档，不一致填原因打回 |
| **看板** | 每人总单量/完成量/在制、返工次数与返工率、工单状态流转、一次通过率 |

## 五个生成参数

坡度档位（%）、台阶高度（m）、碎石密度（块/100m²）、沟槽宽度（m）、涉水深度（m）。
要素**布局只由 seed 决定**（独立随机流 + 晶格值噪声），参数只控制强度与开关，
因此同 seed 同参数的两次生成逐位一致（FNV-1a 高度指纹校验）。

## 关键设计

### 确定性（`src/terrain/`）

- `random.js`：FNV 哈希 + mulberry32 PRNG，每条随机流用 `seed::用途` 派生，与调用顺序无关
- `features.js`：坡道/台阶/碎石/沟槽/涉水五类要素的确定性布局与高度函数
- `TerrainEngine.js`：
  - `generateAll()` 全量生成；`updateParams()` 只重算受影响要素 AABB 覆盖且**未锁定**的区块
  - 锁定顶点掩码覆盖共享边顶点，重算时冻结；未锁定侧用 3m 过渡带 smoothstep 贴合，边界无裂缝
  - 笔刷触及区块自动锁定；解锁清除编辑并重算，结果与全新生成一致
  - `fingerprint()` 量化 0.1mm 后 FNV-1a 哈希，供质检跨机器比对

### WebGPU 渲染（`src/render/`）

- 静态 xz/barycentric 缓冲 + 每帧上传高度缓冲；barycentric 描边实现一键线框，检查坡度与台阶
- 半透明涉水面、区块锁定/编辑/常规三色边框、悬停高亮、拖框矩形
- 轨道相机（左键交互、Shift/右键平移、滚轮缩放），屏幕射线与地面求交做框选/笔刷定位

### 导出（仿真用）

- **高度图**：16bit 灰度 PNG（纯 JS 编码器，无第三方依赖），固定量程 [-1.2, 3.0]m，zTXt 块内嵌 seed/参数元数据
- **OBJ**：257² 规则网格 + 131,072 三角面，x-东/y-上/z-北

### 数据持久化

`src/store/repo.js` 用 localStorage 模拟后端，接口按可替换 REST API 设计；
工单含完整 history、指纹、导出产物名、返工次数。
