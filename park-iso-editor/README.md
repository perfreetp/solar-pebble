# 园区监测微站与巡检路线轴测布置编辑器

基于 **SolidJS + SVG + D3** 的化工园区监测微站轴测布置教学编辑器,供环保培训中心使用:
老师布置点位任务,学员在轴测画布上摆放设备,系统按点位覆盖率自动评分,老师复核打分并汇总成绩与错题。

## 启动

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物在 dist/
```

## 功能对照

| 需求 | 实现 |
| --- | --- |
| 轴测画布摆放设备 | 设备库:监测微站 / 采样探头 / 围栏 / 机柜,点击加入画布 |
| 鼠标拾取 | 点击选中,Shift+点击多选,点空白取消 |
| 三轴变换手柄 | 选中单个物体出现 X/Y/Z 三轴手柄,拖动沿轴移动;直接拖物体为地面自由移动 |
| 包围盒碰撞检测 | 拖动时实时 AABB 检测,越界/碰撞标红,松手推回原位 |
| 贴地吸附 | 开启后物体底座始终吸附到「场地设置」中的地面高程 |
| 90° 步进旋转 | 工具栏按钮或快捷键 `R`,旋转后碰撞则自动回退 |
| 批量复制 | 多选后工具栏按钮或 `Ctrl+D`,自动寻找不冲突的落点 |
| 镜头切换 | 四个轴测角(东北/东南/西南/西北)+ 俯视图,切换时自动取景 |
| 物料清单与占地面积 | 「物料清单」页统计数量/单台占地/场地利用率,俯视图下可导出 CSV |
| 参数面板 | 点选任意物体查看/编辑位置、朝向与设备参数 |
| 老师出题 | 「点位任务」选择设备类型后在画布上加点,可设覆盖半径、拖动点位 |
| 自动评分 | 学员提交后按点位覆盖率自动评分,实时显示覆盖率与未覆盖点位 |
| 老师复核 | 「成绩」页查看学员布置快照、复核打分、写评语 |
| 成绩与错题汇总 | 学员成绩汇总表 + 未覆盖点位排行,可导出成绩 CSV |

## 操作

- 左键拖动空白处平移,滚轮缩放(D3 zoom)
- 拖动物体 = 地面移动;拖动轴手柄 = 单轴移动(0.5 m 网格吸附)
- `R` 旋转 90° · `Ctrl+D` 复制 · `Delete` 删除 · `Esc` 取消选择

## 数据

场景、任务点位、提交记录保存在浏览器 `localStorage`,刷新不丢失。

## 代码结构

```
src/
  iso.js            轴测投影/反投影、深度排序、地面圆投影
  model.js          设备类型定义(尺寸/颜色/默认参数)
  geometry.js       AABB 包围盒、碰撞校验、覆盖率、物料清单、CSV 导出
  store.js          Solid store 全局状态与全部动作(含 localStorage 持久化)
  components/
    Canvas.jsx      SVG 画布:D3 缩放平移、拾取、拖动、碰撞回退、任务点位
    Shapes.jsx      轴测盒体渲染、设备装饰、三轴手柄
    Palette.jsx     设备库与场地设置
    ParamPanel.jsx  参数面板
    TaskPanel.jsx   点位任务(老师出题/学员提交)
    ScorePanel.jsx  成绩复核与错题汇总
    BomPanel.jsx    物料清单与占地面积
```
