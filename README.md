# 工业园区监测设备三维布点编辑器

Vue 3 + PixiJS 实现的等轴测(2.5D)布点编辑器,面向园区环境监测站布点运维组。

## 运行

```bash
npm install
npm run dev    # http://localhost:5173
npm run build  # 产物在 dist/
```

## 功能对照

| 需求 | 实现 |
| --- | --- |
| 导入厂区底图、带标高等轴测场景 | 顶栏「导入底图」,图片按地图范围仿射贴合到等轴测地面;管廊/围墙/建筑按标高拉伸成立体,标注 `+H m` |
| 设备库拖入 | 左栏微型空气站 / 噪声传感器 / 采样探头 / 气象杆,HTML5 拖放入画布 |
| 深度排序点选 | 按 (x+y+z) 深度键从前往后做面片级点-in-多边形拾取,前后遮挡命中正确 |
| 轴向变换手柄 + 实时坐标 | 选中后显示 XYZ 三轴箭头,沿轴拖拽;右侧面板与拖动浮条实时显示 X/Y/Z |
| 安装面自动吸附 | 指针按各候选面高度反解世界坐标,吸附到视觉指向的最高合法面(地面 / 管廊顶 / 围墙顶);非法面红色描边告警 |
| 包围盒相交提示 | 旋转后 AABB 两两求交,相交设备红色轮廓 + 顶部横幅提示 |
| 旋转 15° 档位 | Q/E 键或属性面板 ±15° 按钮,任意输入均吸附到 15° 整数倍 |
| 俯视正交出图 + 支架清单 | 顶栏切「俯视正交」,「导出布点图」下载 PNG;「支架清单」弹窗含支架长度(采样高度 − 安装面标高),可导 CSV |
| 运营后台 | 顶栏切「运营后台」角色,维护设备外形尺寸、允许安装面、区域布点目标,保存即重算吸附与碰撞 |
| 站长审核 | 「提交站长审核」→ 站长角色逐条通过/退回并填意见 → 退回条目在审核页可点击定位到场景设备(闪烁标记) |
| 看板 | 「看板」页签按区域统计已布点 / 目标 / 待布点数量与进度条 |

数据持久化在 localStorage(设备、方案、审核记录、后台配置),顶栏可一键清空重置。

## 操作

- 左键拖设备移动;拖空白处平移;滚轮缩放;双击或 `F` 复位视图
- 选中后拖 XYZ 轴手柄沿轴移动;`Q`/`E` 旋转;`Delete` 删除
