# 商业航天发射场平面布局图 · 分层审片工具

面向发射场平面布局图审片场景的 Web 端分层查看与协同审片应用。基于 **SolidJS + Canvas2D + OffscreenCanvas**，
可流畅承载数万个点 / 线 / 面要素，支持瓦片化离屏渲染、四级 LOD、图层管控、命中拾取、版本快照与双版本差异对比。

## 功能清单

### 渲染与性能
- **离屏分块预渲染**：每个 LOD 级别把世界切成固定尺寸瓦片，用 `OffscreenCanvas`（不支持时回退普通 canvas）预渲染；
  主画布每帧只合成当前视口覆盖到的瓦片，配合 LRU 缓存（默认 160 张）与 `requestIdleCallback` 空闲调度。
- **四级 LOD**：随比例尺在 0（概览）→ 3（最详细）间切换，逐级改变聚合半径、线面简化容差（Douglas–Peucker）、
  线宽、标签密度与面要素表现；概览级面对象退化为中心标记。
- **同类合并与密度抽稀**：点要素按屏幕距离贪心聚合（带计数气泡）；线 / 面要素按质心屏幕网格抽稀；
  标签按优先级 + 屏幕网格抽稀。所有抽稀按要素 id 稳定排序，平移缩放时不闪烁。
- **交互稳定**：缩放瞬间抓取当前帧做半透明过渡，瓦片重建期间不出现白屏；拖拽只改相机偏移，瓦片增量补齐。
- **网格空间索引**：均匀网格（Uniform Grid）登记要素包围盒，命中检测与视口查询只扫描候选格子，30,400 要素下点查询为常数级。

### 图层（七类业务要素）
塔架、导流槽、加注区、避雷塔、警戒线、消防通道、摄像点位。每个图层支持：
- 单独显隐开关
- 透明度调节（10%–100%）
- 叠放顺序调整（实时改变瓦片绘制次序）

### 拾取与选择
- 鼠标悬停高亮（黄色描边 + 辉光）
- 点击打开属性卡，展示完整要素属性与几何信息
- `Ctrl/⌘ + 点击` 加选、`Shift + 拖拽` 框选，支持多要素属性卡并列查看
- 命中检测走网格索引，并按图层可见性与当前 LOD 门控

### 审片协同
- **版本快照**：每次「提交新版本」生成不可变快照（要素全量 + 批注），版本间可一键切换。
- **打点批注**：批注模式下在图上任意位置放置锚点（可关联命中的要素），填写审片意见。
- **逐条回复**：制作方对每条批注填写处置说明，标记「已处理」或「驳回」，状态与回复线程随批注持久化到 `localStorage`。
- **双版本并排对比**：左右两个画布相机完全联动，差异要素按
  <span style="color:#16a34a">**新增=绿**</span> /
  <span style="color:#dc2626">**删除=红**</span> /
  <span style="color:#eab308">**修改=黄**</span> 着色，并给出差异计数汇总。

## 操作方式

| 操作 | 效果 |
| --- | --- |
| 鼠标左键拖拽 | 平移画布 |
| 滚轮 | 以光标为锚点缩放（自动切换 LOD） |
| 点击要素 | 打开属性卡 |
| `Ctrl/⌘ + 点击` | 加选 / 取消加选 |
| `Shift + 拖拽` | 框选多选 |
| 悬停 | 要素高亮 |
| 「打点批注」按钮 + 点击画布 | 放置批注锚点 |

## 技术结构

```
src/
├── types.ts              # 数据模型（要素/图层/版本/批注/差异）
├── layers.ts             # 七图层元信息、LOD 比例尺分级
├── data.ts               # 确定性模拟数据（3 万+要素）与版本派生
├── review.ts             # 版本快照、差异计算、localStorage 持久化
├── store.ts              # Solid store：全局状态与审片动作
├── lib/
│   ├── geometry.ts       # 坐标变换、包围盒、点线距离、DP 简化、多边形判定
│   ├── spatial-index.ts  # 均匀网格空间索引
│   ├── hit-test.ts       # 点拾取 / 框选（含 LOD 与可见性门控）
│   ├── rng.ts            # 确定性伪随机（mulberry32）
│   └── map-view.ts       # 画布视图：事件、相机、瓦片合成、高亮/批注覆盖层
├── render/
│   ├── lod.ts            # 四级 LOD 策略、点聚合、要素/标签密度抽稀
│   └── tile-renderer.ts  # OffscreenCanvas 瓦片渲染、LRU 缓存、样式签名
└── components/           # Solid 组件（画布、图层面板、属性卡、批注、版本栏、对比视图）
```

## 开发与验证

```bash
npm install
npm run dev          # 开发服务器（默认 5180 端口）
npm run build        # 类型检查 + 生产构建
npm run preview      # 静态预览构建产物

npm run test:unit         # 数据规模/索引/差异/LOD 冒烟测试（Node）
# 以下端到端测试需先启动 dev 或 preview，并安装系统 Edge（puppeteer-core 驱动）
npm run test:e2e          # 21 项功能端到端（渲染、图层、拾取、批注、版本、对比）
npm run test:stability    # 拖拽帧率、切图层稳定性、缩放无白屏
npm run test:persistence  # 批注刷新持久化
```

> 模拟数据由固定种子确定性生成（约 30,400 个要素：18,000 摄像点、6,000 避雷塔、3,200 消防通道、
> 2,400 警戒线、420 塔架、220 导流槽、160 加注区），每次刷新结果一致，便于复现与测试。
> 接入真实数据时替换 `src/data.ts` 的 `generateFeatures` 输出为接口数据即可，其余渲染 / 审片链路不变。
