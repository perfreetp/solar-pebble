# 熔岩管工坊 · 月球熔岩管地下基地体素建模与制单平台

给基地概念设计组用的内部工具：一半是 **WebGL2 体素建模器**，一半是 **接单 / 分派 / 质检的工单系统**。

建模器按体素块搭熔岩管洞体与基地舱段，支持 Z 轴分层编辑、镜像对称、选区复制粘贴与阵列、按颜色填充替换材质，
合并前自动体检（悬空体素簇、薄壁），最后按面数减面导出带材质与尺寸的 OBJ 包。
工单系统负责接单录要求 → 分派师傅 → 提交质检 → 不合格打回并累计返工次数 → 看板统计完成量与返工率。

## 快速开始

```bash
npm install
npm run dev          # API :8788 + 前端 :5174（开发模式，热更新）
```

生产模式：

```bash
npm run build
npm start            # 单端口 :8788 同时提供 API 与前端
```

打开 <http://localhost:8788>（开发模式用 <http://localhost:5174>）。

右上角头像可切换当前操作人 —— 这是车间共用终端的"谁在坐班"设定，不是登录鉴权。
权限在**服务端**按角色校验，前端只是按角色隐藏入口。

| 角色 | 能做什么 |
| --- | --- |
| 前台接单（周岚） | 接单、录要求、分派师傅、标记交付 |
| 建模师傅（陈砚 / 许宁 / 罗青 / 何一鸣） | 只有承接该单的人能改模型、提交质检 |
| 质检（沈铎） | 抽查、判定通过、打回（必须写问题说明） |
| 组长（林澈） | 全部权限 + 导出交付 |

## 四个界面

### 接单台 `/orders`
按状态 / 人员筛选工单，左侧实时显示每位师傅的在制与完成量。
点单看详情抽屉（要求、模型状态、体检摘要、质检记录、完整动态），可当场分派或进建模台。
"接单"表单里能直接录体素网格尺寸与体素边长，并换算成实际米数。

### 建模台 `/build/:id`
中央 WebGL2 视口，左工具与材质，右镜像 / 选区 / 体检 / 要求，底部 Z 轴层条。

**工具与笔刷**
- 放置（B）、擦除（E）、框选（S）、吸取材质（I）、平移（空格拖拽）
- 笔刷 1 / 3 / 5 / 7，只在当前编辑层落子
- 在空白处点击会落在当前层平面上，方便"空中起建"

**Z 轴分层**
- 层条每格一层，按填充密度着色；点击设为编辑层，Shift 点数层扩展范围，Alt 点单独显示该层
- "可编辑层 1–96"输入框限定只有这几层能改（其余层自动视为锁定）
- 每层可单独锁定（L）；"仅显示"框支持 `1-6, 20` 这种写法，只渲染指定层
- "聚焦"把编辑层范围外的部分压暗

**镜像对称**
开关一开，轴线一侧的每次落子都会在另一侧同步生成镜像体素（撤销时一起回退）。
轴线可用滑块或"居中 / 左右移"精确调到中线。

**选区**
框选后浮出工具栏：复制、剪切、粘贴、填充、仅填空气（灌浆）、阵列、删除。
- 复制/粘贴保留材质与相对位置
- 阵列复制可按 X / Y / Z 三向复制最多 64 份，间距按整份尺寸排布即可无缝拼接
- 替换材质支持"所有材质""按材质组""指定材质"三种来源

**材质分层**
16 种材质分四组：洞体（玄武岩 / 角砾岩 / 月壤固结层）、内壁（密封衬里 / 隔热衬层 / 钢衬板）、
舱体（钛合金舱壁 / 复合壁板 / 舱内地板 / 观测舷窗 / 气闸框 / 散热板）、设备（支撑桁架 / 照明带 / 管线槽 / 地基锚固）。
悬停时底部 HUD 显示命中体素的材质名与编号。

### 质检台 `/qc`
待质检 / 已打回 / 已通过三个队列。选中一单后自动跑体检并渲染只读三维预览，
可在悬空簇与薄壁区域的定位标签上点按跳转。

**自动核验**用几何数据直接判定可量化的项：
外形尺寸、体素网格、有效层数、镜像对称度、材质分组、原始精度面数。
剩下的"气闸对位"这类需要人眼判断的项留给质检手动勾。

打回必须写问题说明（提供常见问题快捷标签），打回后返工次数 +1 并记入动态。

### 看板 `/dashboard`
工单总数 / 已交付 / 累计返工 / 超期四个 KPI，各师傅完成量堆叠条形，
返工率与一次通过率排行，状态分布，近 14 天送检 / 打回 / 通过节律，质检队列与最近动态。

> **返工率口径**：被打回过的工单数 ÷ 已送检工单数（0–100%）。
> 另给"均次"= 每条送检工单平均被打回几次，避免把次数和比例混在一起。

## 合并前体检

导出前会检查两类结构问题，建模台与质检台共用同一份算法（`shared/validate.js`）：

**悬空体素簇** —— 6 邻域连通分量标记，与主体不连通且**超过 5 格**的簇会报出来，
并给出最大簇的定位按钮（点按即跳转取景）。5 格及以下只作"零碎体素"提示，不阻塞合并。
存在悬空簇时**提交质检会被服务端拒绝**（422）。

**薄壁** —— 判的是"法向壁厚"：只有某轴向为该体素的暴露面（该侧是空气）时，
这一轴的连续实体长度才计入。这样圆柱壳切线方向的短行程不会被误判成一圈薄壁。
默认阈值 **< 2 格**，两侧阈值都可在界面里调。

## OBJ 导出

合并成一个网格后按面数减面，导出 zip 包：

```
LT-2608-full.obj            四边形网格，按材质分 usemtl 段
LT-2608-full.mtl            Kd / Ks / Ns / Pr / Pm，自发光材质写 Ke
LT-2608-full.metadata.json  尺寸、包围盒、面数、材质清单、订单信息
LT-2608-full.readme.txt     导入说明
```

- **减面**：1× / 2× / 3× / 4× 四档降采样（取每 k³ 块里占多数的非空材质），界面显示每档的面数与体素尺寸
- **分层导出**：可只导"当前可编辑层"或手写 `1-24, 30-48`，便于分件加工
- **尺寸**：单位米，X/Y 以模型中心为原点，Z=0 为基准地面；obj 头部注释与 metadata 都写了实际外形尺寸
- OBJ 按 `v → vn → f` 三段输出并按材质分桶，不用非标准的 `vc` 行，避免部分 DCC 导入异常

## 技术实现

```
shared/          前端与服务端共用的内核
  materials.js   材质字典（id / 颜色 / 分组 / 自发光）
  voxel.js       稠密 Uint8 体素网格，含批量编辑与撤销变更记录
  validate.js    悬空簇 / 法向壁厚 / 体检报告 / 问题定位标记
  mesh.js        贪心合面（含顶点 AO）、降采样、OBJ + MTL 生成
server/
  index.js       REST API：订单流程、模型存取、体检、结构核验、导出
  store.js       JSON 文件存储（原子写入）+ 种子数据
  seedModel.js   生成带剖面、内壁衬里与舱段的起点熔岩管模型
src/
  editor/        WebGL2 渲染器与编辑会话
  views/         四个界面
  components/    弹窗、抽屉、状态标签等
```

**为什么体素内核对前后端共用**：服务端提交质检时要用同一份算法复核，
否则师傅在本地看到"可合并"、提交却被拒，或者反过来漏掉问题。

**渲染**：32³ 区块贪心网格，编辑后只重建脏区块。着色是半球光 + 主光 + 相机补光 + 顶点 AO，
sRGB→linear→ACES 近似 tonemap。隐藏层不生成面，所以"仅显示某几层"是真正省几何的，
切层后能直接看到内部结构。

**拾取**：射线对体素做 DDA 穿越，返回命中体素与进入面，放置时沿法线外推一格。

**撤销**：每次操作产生 `{x,y,z,before,after}` 变更列表；一次拖拽的多次落子在 `endStroke` 时合并成一步。
镜像镜像出来的格子也在同一份变更里，所以撤销必然成对回退。

## 测试

```bash
npm test           # 72 项：内核算法 + 编辑器行为 + HTTP 流程（Node 内置 test runner）
npm run test:ui    # 23 项浏览器验收（需先 build 并 start）
npm run test:all   # 两者都跑
```

- `tests/kernel.test.mjs` —— 面剔除、贪心合并、悬空阈值边界、法向壁厚、镜像索引、降采样、OBJ 结构
- `tests/editor.test.mjs` —— 镜像落子与撤销、图层锁定、笔刷、框选填充/替换、复制粘贴、阵列、solo
- `tests/flow.test.mjs` —— 起真实服务跑完整工单链路：接单→分派→保存→提交→打回→返工→通过→交付→导出，含角色越权校验
- `tests/interact.mjs` —— 浏览器里真实鼠标拖拽：画笔、擦除、镜像、框选、填充、阵列、图层、聚焦、保存
- `tests/smoke.mjs` —— 四个界面的验收，并校验导出 zip 与看板指标
