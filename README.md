# 潮沟网络工作台

面向海岸带调查队的程序式潮沟网络生成与归档工具。原生 TypeScript + Web Components + WebGPU，无运行时依赖。

输入主沟走向、分叉角度、支沟密度、曲流幅度与随机种子，生成主干 / 支沟 / 毛细沟三级潮沟网络；
可手工编辑、锁定局部、改走向后整体重生成并保持锁定段形态；
支持按级别调透明度、按沟长/密度/高程分级配色、导入航拍底图、版本并排比对、出调查说明，
并可按年份、区域、沟级别检索归档成果。

## 快速开始

```bash
npm install
npm start            # 构建并启动 http://localhost:8080
```

需要支持 WebGPU 的 Chrome / Edge（Chrome 113+）。若 GPU 被策略限制，可用
`--enable-unsafe-webgpu --enable-unsafe-swiftshader` 启动；WebGPU 不可用时界面会明确提示，
生成、编辑、归档等功能仍可用（只有 3D 视图不可用）。

## 命令

| 命令 | 作用 |
| --- | --- |
| `npm run build` | 打包 `src/` 到 `dist/` |
| `npm run serve` | 静态服务 `dist/`（默认 8080，`PORT` 可改） |
| `npm start` | 构建 + 启动 |
| `npm run typecheck` | `tsc --noEmit` |
| `npm test` | 核心算法单元测试（Node 内置 test runner） |
| `npm run e2e` | Playwright 端到端测试（含 WebGPU 渲染校验） |
| `npm run check` | 类型检查 + 单元测试 + 端到端测试 |

端到端测试需要本机已安装 Chrome；截图输出到 `artifacts/`。

## 参数

| 参数 | 范围 | 说明 |
| --- | --- | --- |
| 主沟走向 | 0–359° | 自正北顺时针，决定网络伸向滩面的方向 |
| 分叉角度 | 8–110° | 一对支沟相对父沟展开的总夹角 |
| 支沟密度 | 0–100% | 控制支沟与毛细沟的发育数量与间距 |
| 曲流幅度 | 0–100% | 中心线蛇曲强度（带限方向噪声） |
| 随机种子 | 任意字符串 | 同参数 + 同种子 ⇒ 完全一致的结果 |
| 沟头终止高程 | 0.6–2.6 m | 滩面升到此高程时沟道自然尖灭 |
| 滩面比降 | 0.2‰–3‰ | 向陆方向的高程抬升率 |
| 口门基准高程 | 0–0.8 m | 主沟口门处的滩面高程 |

分级参数（每级的宽度衰减、弯曲噪声倍数）可在「分级参数」折叠区独立微调。

## 确定性保证

- 随机数全部来自自实现的 splitmix32 流，**每个流由 `(种子, 用途, 父沟, 序号)` 派生**，不依赖生成顺序；
- 不使用 `Math.random()`，不使用平台相关的浮点操作（无 `sin` 大相位相加等）；
- 结果指纹 `fingerprint` 由参数与全部中心线坐标量化后 (毫米/微弧度级) 散列得到；
- 测试覆盖：同参数两次生成逐点相等、换种子必变、每个参数都真正参与生成、恢复原参数回到原指纹。

## 三级结构与宽度

| 级别 | 宽度衰减 (每 100 m) | 弯曲噪声倍数 | 分叉间距 |
| --- | --- | --- | --- |
| 主干 | 10% | 0.80× | 380 → 130 m (随密度) |
| 支沟 | 28% | 1.15× | 210 → 78 m |
| 毛细沟 | 45% | 1.55× | 170 → 62 m |

- 沟宽沿程按 `口宽 × (1 - 衰减)^(s/100)` 收窄，沟头最后 30% 再作尖灭；
- 子沟口宽 = 父沟局部宽度 × 比例（随密度 0.40–0.58）；
- 交汇处用 SDF 胶囊片元 + 交汇口圆盘融合，得到圆角过渡；
- 沟头按高程自然收尾，并记录 `stopReason`（elevation / collision / extent / maxLength）。

## 锁定段

点击「锁定」工具或沟道档案里的「锁定此段」：

1. 以**起点为原点、起点切向为 +x** 保存该沟的局部坐标（`localPts`）与刚体不变形状签名；
2. 重生成时，新父沟算出新的汇入点与切向，锁定段只做**刚体变换**（旋转 + 平移）落到新位置；
3. 起点严格贴在父沟上 ⇒ 自动接合；长度、弯曲、偏转逐点不变；
4. `lockReport` 给出每段的形态签名校验与接合误差（正常为 0）。

改变主沟走向后整体重生成，锁定段依然保持原形态并接回新网络；父沟消失时会被标为孤段并提示。

## 配色与视图

- **按级别**：主干 / 支沟 / 毛细沟三色；
- **按沟长 / 局部密度 / 沟头高程**：各 5 级分位配色，图例给出断点；
- 各级透明度独立可调（0–100%），可单独隐藏某级；
- 滚轮缩放、拖动平移、双击全图、触屏双指缩放；
- 地形底图渲染高程渐变、等深线与 100 m 测量网格。

## 航拍底图

「导入航拍底图」读入图像，按当前网络范围配准（可在档案中调整范围、透明度、亮度、翻转），
并保留原始像素尺寸与航片编号，写入档案。

## 归档、版本与调查说明

- **编号档案**：`TC-年份-区域代号-序号`，含参数、指纹、三级统计、锁定数、底图信息；
- **检索**：按年份 / 区域 / 沟级别 / 关键词；
- **历史版本**：每次「存为版本」保存完整几何快照，最多 40 个/档案；
- **并排比对**：左侧历史版本、右侧当前结果，附逐项差值表；
- **调查说明**：参数、三级结构表、分级断点、野外校核要点，可复制或下载 `.txt`；
- **导出**：CSV 属性表、GeoJSON（中心线 + 宽度/高程属性）；
- **档案库**：整体导出/导入 JSON。

```
  core.test.mjs    核心算法测试
  e2e.mjs          端到端测试
```

## 已知限制

- 归档库存在浏览器 `localStorage`（单浏览器、单设备）；跨设备请用「导出档案库」。
- 地形为解析高程场，用于表达"沟头按高程收尾"的物理依据，不是实测 DEM。
- 毛细沟在极高密度下会因净距约束提前收尾（`stopReason = collision`），这是有意为之的避让。
