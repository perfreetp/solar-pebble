# 撞击坑体素建模与素材批次放行控制台

面向陨石坑科考展馆的桌面工具:用 **SolidJS + three.js** 完成撞击坑地形的半米体素建模,以及展陈素材批次的自动检查、复核与放行。

## 启动

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 生产构建
npm run typecheck  # 类型检查
```

浏览器自动化测试(需本机 Chrome,测试脚本通过 puppeteer-core 驱动):

```bash
npm run dev &          # 先起开发服务器
npm run test:ui        # 四界面端到端冒烟(21 项)
npm run test:voxel     # 体素编辑核心交互(11 项)
```

## 四个界面

| 界面 | 职责 |
| --- | --- |
| **体素建模** | 半米体素在坑缘/坑底堆积、擦除;三编辑层显隐与锁定;镜像对称;框选复制粘贴;合并减面;导出前扫描;GLB 导出 |
| **素材批次** | 拖入/登记一批素材,自动逐项跑规则检查,问题按严重/提示两级展示 |
| **复核台** | 复核员对每条问题逐条「确认 / 驳回」,记录复核人与进度,支持整条目一键处理 |
| **放行中心** | 整批达标判定闸门;达标才放行入库,含驳回项则整批退回供应方并附退回工单 |

## 建模能力与实现要点

- **半米体素**:`VOXEL_SIZE = 0.5m`,49×49 格网格,初始地形由解析撞击坑剖面(坑底-坑壁-坑缘-溅射毯)生成。
- **三个编辑层**:按深度分表土 / 溅射层 / 基岩,各自独立显示、锁定;锁定层不接受堆积、擦除或粘贴写入。
- **镜像对称轴**:x=0 平面,开启后堆积、擦除、粘贴在对称侧自动同步。
- **框选复制粘贴**:轴对齐框选一段坑缘体素复制到剪贴板;粘贴时以落点表面法线主导轴做轴对齐转向,贴到命中表面外侧,重叠体素自动避让。
- **合并减面**:
  1. **贪婪网格化(greedy meshing)**先把相邻同层共面合并成大四边形,通常已把面数压到原始体素模型的约三成且视觉无损、地形连通;
  2. 当面数预算比贪婪结果更激进(如「一键减到两成」)时,再用 three.js `SimplifyModifier`(meshoptimizer WASM)二次塌缩到目标比例。
  面数统计以「逐体素独立暴露面」为原始口径,界面如实展示原始 → 贪婪 → 最终三段数字。
- **导出前扫描**:检测孤立体素(无六邻接)与悬空面(上下均无体素),在视口红色高亮;GLB 导出前强制再扫一次,有未处理问题则拦截。
- **GLB 导出**:`GLTFExporter` 输出二进制 glTF,三层各为一个命名子网格。

## 素材检查规则

`src/materials/checkRules.ts`,分级:

- **严重(阻断放行)**:格式不在白名单、空文件、批次内校验和重复、纹理/模型无法识别层归属。
- **提示(需人工确认)**:命名不规范、缺分辨率标记、纹理/模型超大、模型缺配套贴图、数据文件字段存疑。

放行闸门要求:无待处理问题、无被驳回的严重项、无驳回条目。状态持久化在 `localStorage`。

## 目录结构

```
src/
  voxel/
    constants.ts       # 体素尺寸、撞击坑剖面、初始地形、层定义
    voxelStore.ts      # 体素状态仓库(层/镜像/选区/剪贴板/扫描)
    greedyMeshing.ts   # 贪婪网格化
    meshes.ts          # 合并减面 + GLB 导出
    CraterScene.ts     # three.js 场景:实例化渲染、拾取、框选、高亮
  materials/
    checkRules.ts      # 素材检查规则引擎
    materialStore.ts   # 批次/复核/放行状态机
  views/               # 四个界面
  components/          # 通用组件(Toast、状态标签)
scripts/
  smoke.mjs            # 四界面端到端测试
  voxel-test.mjs       # 体素编辑交互测试
```
