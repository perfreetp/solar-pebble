# 拆装式床架三维布置工作台

面向床厂**拼装工艺员**的拆装式钢管床架三维布置编辑器。SolidJS + PixiJS 前端，Express + SQLite 后端，
覆盖从零件库拖放排布、等轴测三维装配、装箱通道校核、物料清单导出，到版本提交、主管评审、客户只读分享的完整工艺闭环。

---

## 快速开始

```bash
npm install
npm run dev          # 同时启动 API（:9077）与前端（:5188）
```

打开 http://localhost:5188 。用顶栏右上角的身份徽标可在 **李工（工艺员）** 与 **张主管（主管）** 之间切换演示。

生产构建：

```bash
npm run build
npm start            # 单进程同时提供 API 与静态前端，默认 :9077
```

其它命令：

```bash
npm run typecheck    # TypeScript 全量类型检查
npm test             # 几何 / 场景 / 后端流程单元测试（node:test）
```

端口可用 `PORT`（API）和 `vite.config.ts` 的 `server.port`（前端）调整。数据保存在 `data/kd-studio.db`（node:sqlite，WAL）。

## 功能对照

### 三维布置（主工作台）

| 能力 | 实现 |
|---|---|
| 零件库拖入场景 | 左侧「零件库」Tab，拖拽零件卡到画布，或点 `+` 放到视图中心；按插接/碰撞自动判位 |
| 钢管件 / 注塑连接件 / 床板 / 包装箱 | `shared/parts.ts` 零件库，含规格、材质、密度、壁厚、插接点定义 |
| 等轴测投影 + 深度排序 | `shared/geometry.ts#project`（±30° 等轴测），PixiJS 画布按 OBB 中心深度排 `zIndex` |
| 选中被挡住一半的管件 | 射线拾取返回前→后命中列表；**同一处再次点击逐层穿透**，顶部提示「此处叠放 N 个零件」 |
| 三轴变换手柄平移 | 选中件顶部绘制 X / Y / Z 手柄 + 旋转环；X/Y 沿世界轴平移，Z 升降，外圈旋转 |
| 框选一组件整体挪 | 空白处拖拽框选（多选高亮），整组随三轴手柄平移 / 旋转，按整体包围盒吸附 |
| 拖动时包围盒干涉检测 | 拖动中实时做 OBB 足迹多边形裁剪求交，命中件描边标红 |
| 撞上标红并拒绝落位 | 松手时若仍干涉 → 回退到拖动前位置并提示「落位会与其它零件干涉，已退回原位」 |
| 松手吸附地面或下方件顶面 | `supportHeight()`：按足迹重叠面积找最近支撑面（地面或下方件顶面） |
| 转角吸附 15° | 旋转手柄按 15° 取整；属性面板也可输入任意角或 ±15° 按钮 |
| 床腿插接点吸附提示并对孔 | 拖动时检测 pin↔socket 且同径的插接对（阈值 90mm），画绿色对位线与「连接件↔零件 距离」气泡，松手精确对孔并建立连接 |
| 左侧层级树点击聚焦 | 层级树按图层分组，点条目即选中并动画聚焦镜头；`⌖` 单独聚焦 |
| 右侧属性改尺寸 / 材质色 | 尺寸 W/D/H 实时改（同步重量与 BOM）；材质色色板 + 自定义取色 |
| 锁定 / 隐藏图层 | 层级树与属性面板均可切换整层显隐与锁定；锁定图层不可选中编辑、不可删除、不可落位 |

### 俯视图与出图

- 顶部切到「俯视出图」：自动生成**正投影线框布局图**。
- 被上方零件遮挡的构件以**虚线轮廓**绘制（隐藏线）；按实体高度排序叠绘。
- **通道宽度自动标注**：对相邻构件簇之间的空隙做通道检测并标注毫米数；`< 800mm` 标红、汇头顶部「通道宽度不足 N 处」；外圈工作通道以虚线示意。
- 含比例、外廓尺寸标注、图例与标题栏。

### 统计与物料清单

- 右侧「统计 / BOM」Tab：零件总数、总重量、总体积、干涉数，按类别小计，通道检查，BOM 明细。
- 顶栏 **⭳ BOM** 或统计面板导出 **CSV**（含 BOM 头，Excel 友好，含分类小计）。
- 统计面板「通道检查」可导出俯视布置说明文本。

### 版本 / 评审 / 分享

- **保存版本**：命名 + 变更说明，保存成草稿；可「保存为草稿」或「保存并提交评审」。
- **版本历史**：按状态筛选，缩略俯视图，查看详情、载入编辑（草稿 / 退回版）。
- **主管评审中心**：待评审列表，详情内含俯视图、干涉报告、BOM、全流程日志；**退回必填原因**，通过后可生成**客户只读链接**。
- **客户只读页** `/share/<token>`：仅展示俯视图与物料清单，无任何编辑入口；仅当版本已评审通过才可访问（草稿分享返回 409）。

## 架构

```
shared/            # 前后端共享的纯领域逻辑（无 DOM 依赖）
  types.ts         # 领域类型：零件、实体、BOM、俯视图、干涉、版本
  parts.ts         # 零件库 + 重量/体积计算（按截面积，非包围盒）
  geometry.ts      # 等轴测投影 / 射线拾取 / OBB 干涉 / 通道检测 / 插接吸附 / 支撑面
  scene.ts         # 示范场景（整床 + 装箱姿态）

server/
  db.ts            # node:sqlite 建表、演示用户
  index.ts         # REST API：版本 CRUD、提交流转、评审、只读分享、静态前端

src/
  index.tsx        # 路由（hash 路由 + 路径式分享链接）
  lib/api.ts       # API 客户端
  lib/export.ts    # CSV / 文本导出
  editor/
    store.ts       # 编辑器状态：选择、拖动/吸附/干涉回退、撤销重做、相机、图层
    pixi.ts        # PixiJS 等轴测渲染：盒体/管件着色、描边、手柄、吸附提示、拖放幽灵
    Canvas.tsx     # 画布组件：指针交互、拾取穿透、框选、缩放平移、拖放
  components/      # 左面板（零件库/层级树）、右面板（属性/统计）、俯视图、BOM、缩略图
  pages/           # 工作台、版本历史、评审中心、客户只读页
  styles/app.css
test/              # geometry.test.ts / api.test.ts
```

### 渲染要点

- **投影**：`project(x,y,z) = ((x−y)·cos30, (x+y)/2 − z)`，无透视，等轴测。
- **拾取**：投影点反推射线，从 z=10000 向下行进（与相机同向），`t` 最小者为最前，天然支持穿透选择。
- **干涉**：两 OBB 在 XZ 平面做足迹多边形裁剪（Sutherland–Hodgman）求交面积，Z 向重叠取正；共享连接（`scene.joints`）的零件跳过。
- **吸附优先级**：松手时**先试插接对孔**（精确），无插接才落到最近支撑面。

## 说明

- 演示身份通过 `x-user-id` 头在三个固定用户间切换，无真实登录；生产接入需替换为鉴权中间件。
- 数据持久化在本地 SQLite，版本快照存整场景 JSON + 预计算的 BOM / 俯视图 / 干涉报告，评审与分享读取快照，不受后续编辑影响。
- 零件重量：管件按 `π(do²−di²)/4 × 长度 × 密度` 计算（薄壁），板材 / 箱体按包围盒；均同步进物料清单。
