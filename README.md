# 运载火箭体素建模工作台

面向航天科普展陈公司的 Web 端体素建模工具：制作员按展项条目分头搭建**芯级 / 助推器 / 整流罩 / 尾翼**，
主管审核通过后打包 glTF 交付展陈方。纯原生 **TypeScript + Web Components + WebGPU** 实现，零运行时框架依赖。

## 启动

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 类型检查 + 生产构建到 dist/
npm test           # 核心算法冒烟测试（DDA 拾取 / 减面 / 镜像 / 阵列 / GLB 封包）
# 真实浏览器 WebGPU 测试（需先起 dev server，支持 VITE_URL 环境变量）
VITE_URL=http://127.0.0.1:5173/ npm run test:browser
```

> 需要支持 WebGPU 的浏览器（Chrome / Edge 113+）。首次打开会生成一枚演示火箭。

## 三个页面

| 页面 | 职责 |
| --- | --- |
| 项目页 | 展项条目列表：编号、负责人、**截止时间**（逾期红标）、状态、**退回次数 0/2**（达上限锁定）、新建条目 |
| 建模页（主体） | 128³ 网格上的体素建模、分层大纲、框选、镜像、导出 |
| 预览页 | 只看成品、**自动绕飞**、只读，可暂停/继续 |

条目状态流：制作中 → 待主管审核 →（退回，最多 2 次，超限锁定）→ 审核通过 → 打包交付。

## 建模页能力

- **体素笔刷**：在 128×128×128 网格上放置 / 擦除 / 吸色 / 换色，笔刷直径 1–9
- **法线落子**：CPU DDA 射线拾取，高亮命中面并沿其面法线落子；与已有体素不重叠（同格同层为换色）
- **相机**：左键拖拽旋转、滚轮缩放、右键平移，透视 / **正交视图**一键切换
- **分层大纲**：芯级、助推器、整流罩、尾翼分组；每层支持显隐、锁定，可勾选"只编辑当前层"
- **X 轴镜像**：开启后一侧的增/删/换色同步到对侧；**压在对称面（x=63）上的体素只落一次**
- **框选**：两次点击确定长方体选区，支持复制 / 移动（剪切+粘贴）/ 删除，粘贴时显示幽灵包围盒
- **径向阵列**：助推器层一键绕 Y 轴 90° 阵列成四枚（整数格旋转，无亚体素误差）
- **多层合并**：合并到目标层；导出网格时先做相邻面剔除，再贪心减面（同色共面四边形合并）
- **glTF 导出**：导出前弹窗显示**体素数 / 顶点数 / 三角面数**，超过 **80,000 面**给出超限提醒；输出带顶点色的二进制 `.glb`

## 快捷键

| 按键 | 功能 | 按键 | 功能 |

## 架构

```
src/
├── core/            纯逻辑层（无 DOM、无 WebGPU）
│   ├── types.ts        数据模型、调色板、镜像/网格常量
│   ├── math.ts         vec3 / mat4、透视正交投影、射线-平面
│   ├── voxel-model.ts  体素增删与镜像语义
│   ├── store.ts        项目/设置状态、审核流、localStorage 持久化、撤销栈
│   ├── mesh.ts         相邻面剔除 + 贪心网格合并（greedy meshing）
│   ├── gltf.ts         GLB 2.0 封包（POSITION/NORMAL/COLOR_0）
│   └── ops.ts          框选、剪贴板、径向阵列、层合并
├── render/          WebGPU 渲染层
│   ├── engine.ts       设备/上下文/MSAA+深度帧通道
│   ├── camera.ts       轨道相机（透视/正交、屏幕转射线）
│   ├── voxel-renderer  实例化立方体（每体素 1 实例）
│   ├── overlay-renderer 半透明面/线段（高亮面、选区、镜像面、地面网格）
│   ├── picking.ts      Amanatides–Woo DDA 体素拾取
│   └── voxel-scene.ts  场景装配与帧循环
├── editor/          交互控制
│   └── edit-controller.ts 指针/键盘、笔刷、框选、剪贴板、历史
└── ui/              Web Components（Shadow DOM）
    ├── app-shell / project-page / editor-page / preview-page
    ├── editor-toolbar / layer-outliner
```

数据保存在浏览器 `localStorage`（key: `rocket-voxel-workbench-v1`），清除站点数据即可重置。
