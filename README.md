# 翅纹工坊 · Lepidoptera Wing Lab

自然博物馆文创用的**昆虫翅纹过程式生成工作台**。Svelte 5 + WebGPU,三个模块串成一条生产线：

```
生成器  →  批次  →  复核
制作员      系统自动质检   复核员逐条确认
```

## 运行

```bash
npm install
npm run dev      # http://127.0.0.1:5173(MCP 环境里可能顺延到 5174/5175)
npm run build    # 生产构建到 dist/
npm test         # 24 项内核断言(生成 / 质检 / 导出)
```

浏览器需要支持 WebGPU(Chrome/Edge 113+)。不支持时视口自动回落到 Canvas2D 渲染,功能完全一致,左上角会显示当前后端。

## 一、生成器

### 1. 模板与参数

三个物种模板: **凤蝶**(长尖前翅 + 尾突)、**蛱蝶**(宽翅、翅室密)、**粉蝶**(狭长翅、素色底)。每个模板带一套自己的轮廓、翅脉数和配色默认值。

| 参数 | 作用 |
| --- | --- |
| 翅长 / 翅宽 | 翅的比例;翅长也只作用于缩放,不改变拓扑 |
| 前后翅比例 | 后翅相对前翅的大小 |
| 斑点密度 / 斑点大小 | 斑点的**面积预算**与单点尺寸 |
| 色相起点 / 色相范围 | 配色窗口;所有填色都落在这个色相窗口内 |
| 饱和度 / 明度 | 整体色调 |
| 翅脉密度 | 主脉条数与细脉数量(量化分级,保证翅室 id 稳定) |
| 边缘带宽度 | 外缘带厚度 |
| 对称扰动 | **左右翅唯一的差异来源** |

切物种会重置为该模板的默认参数,并清空种子历史。

### 2. 确定性:同一个种子永远同一只蝶

生成器是一个纯函数:

```
generateSpecimen({ speciesId, params, seed, variant }) → 翅形 + 翅脉 + 翅室 + 斑点 + 配色
```

- 所有随机数来自 `Rng`(FNV-1a 哈希 + mulberry32 播种),**任何地方都不调用 `Math.random()` 或时钟**。
- 几何在每片翅的**局部坐标**里以极坐标轮廓 `(角度 φ → 半径 r)` 生长;摆放只是各翅的一个仿射变换,所以改翅长/翅宽不会打乱翅室拓扑与 id。
- **左右翅由同一份几何镜像得到**:先生成一次,再给两侧挂上各自的 wing key。因此 `对称扰动 = 0` 时左右逐位相同;把它调高,才会出现左右差异——这也正是复核里「左右对称偏差」检查要抓的东西。
- 工具栏的 **✓ 校验确定性** 会用同样的种子和参数重新生成两次并比对完整几何指纹,差异数必须为 0(开发自检用)。

界面上显示每只标本的**指纹**(参数 + 种子 + 变体的哈希),写进导出的 JSON,可用来核对素材是否被改动过。

### 3. 四个变体

一次生成 4 个并排变体,便于挑一个继续打磨:

| | 说明 |
| --- | --- |
| V1 · 原样 | 完全按当前参数 |
| V2 · 宽翅 | 翅幅 +8%,斑点略疏 |
| V3 · 密纹 | 翅脉更密,斑点更多 |
| V4 · 深红 | 色相转红、色域收窄、边缘带加宽 |

变体**也是确定性的**——偏移量是固定表,不是随机数,所以 `(种子, 参数, 变体)` 仍然唯一定位一只蝶。

### 4. 视口

- WebGPU 渲染,4× MSAA;场景是分层三角面片(翅形 / 翅室 / 翅脉 / 斑点),每组一次 draw call。
- 滚轮缩放(以光标为锚点)、空格+拖动或中键平移、`F` 或双击适应窗口。
- 工具栏可逐层显隐:翅形 / 翅室 / 翅脉 / 斑点 / 虫体。

### 5. 手工编辑(核心保证)

**选择工具**下:

- 点**翅室** → 右侧面板可改色(取色器 / 6 个预设色,都取自当前配色)、锁定、还原。
- 点**斑点** → 直接拖动;拖右侧白色圆点改大小;方向键微调。
- **锁定翅室**(`L` 键或面板按钮)会把当前颜色冻结下来。
- `Ctrl+Z` / `Ctrl+Shift+Z`(或工具栏 ↶ ↷)撤销重做,按操作粒度回滚(drag 会合并成一步)。

**再调全局参数重算时**:

```js
regenerate / generateAll({ keepOverrides: true })
  → 用新参数重新生成整只蝶
  → 把 overrides 重新贴回去
```

- 锁定的翅室:**保留**冻结的颜色和锁定状态。
- 手改过的翅室:**保留**手改的颜色。
- 没动过的翅室:**按新参数重算**。
- 移动/缩放过的斑点:**保留**相对偏移量(以翅局部坐标存储,所以翅形变了斑也会跟着走)。

手工改动按变体分别保存,四个变体互不污染。`npm test` 里的 "手工改动" 一组断言就在守这条契约。

## 二、批次

点变体卡片上的「进批次」把标本连同**当时的参数、种子、变体、手工改动**一起提交。提交瞬间系统跑三项自动检查,每条结果分两级:

| 检查 | 度量 | 警告 | 阻断 |
| --- | --- | --- | --- |
| **左右对称偏差** | 左右翅轮廓径向偏差 75% + 斑点位置偏差 25%(在各自的朝外坐标系里比较) | ≥ 3.2% | ≥ 7.0% |
| **斑点密度** | 斑点面积 / 翅面积;以及四片翅之间的极值比 | 覆盖 <1.2% 或 >9%;四翅比 ≥1.5 | 无斑点、覆盖 >14%、四翅比 ≥2.2 |
| **颜色对比度** | 斑点 vs 所在翅室(WCAG 对比度);翅面整体明度跨度;边缘带 vs 边缘翅室 | <1.7:1 / 跨度 <34% / 带 <1.15:1 | <1.3:1 / 跨度 <18% |

另外,左右翅**翅室结构无法一一对应**会直接判阻断(无法对称生产)。

条目列表按 `阻断 / 警告 / 驳回` 计数,右侧显示所选条目的自动检查详情、建议改法和预览。

## 三、复核

复核员逐条 **确认** 或 **驳回** 自动检查项:

- 有**驳回**的条目退回制作员;「退回制作员修改」把该条目原有的参数、种子和手工改动重新载入生成器,改完可以再提交。
- 所有阻断项必须清零,**且每条检查都已确认、没有待复核条目**,「放行并导出素材包」才会解锁。
- 这道闸门写在导出函数内部(`buildAssetPack` 会先校验 `canRelease`),不只是禁用按钮——绕过界面直接调用也拿不到素材包。

### 素材包内容

放行后导出一个 ZIP:

```
winglab-<批次>-<时间>/
├─ README.txt                清单与复现说明
├─ batch.json                批次摘要
└─ 凤蝶-SW-0001-V1/
   ├─ svg/butterfly.svg      整只蝶,按层分组(shape / cells / veins / spots / body)
   ├─ svg/wing-*.svg         四片单翅,翅局部坐标,画笔可直接编辑
   ├─ png/butterfly-2048.png 2048px 透明底成品图
   ├─ png/thumb-512.png      缩略图
   └─ json/specimen.json     参数 / 种子 / 变体 / 指纹 / 手工改动 / 检查结果 / 复核记录
```

SVG 里的翅室和斑点带 `data-cell` / `data-spot` 与稳定的 id,和 JSON 里的记录一一对应。

## 代码结构

```
src/
  lib/
    rng.js              确定性随机(哈希播种 + mulberry32)、指纹
    species.js          三个物种模板:极坐标轮廓、翅脉数、默认参数
    generator.js        核心:轮廓 → 翅脉 → 横脉 → 翅室 → 斑点 → 配色;变体偏移;overrides
    geometry.js         几何工具(Catmull-Rom、弧长采样、三角化、点在多边形内 ……)
    color.js            HSL/RGB、WCAG 对比度、色相映射
    scene.js            specimen → 分层三角面片(渲染与导出共用的唯一真源)
    body.js             虫体 / 头 / 触角形状
    validation.js       三项自动检查与阈值
    svgExport.js        矢量导出(整只 / 单翅)
    export.js           素材包打包(闸门 + SVG + PNG + JSON)
    appState.svelte.js   应用状态、确定性校验、撤销重做、批次与复核流转
    render/webgpu.js    WebGPU 渲染器
    render/canvasFallback.js  Canvas2D 回落渲染器
  lib/components/       GeneratorPanel / Toolbar / Viewport / VariantStrip / InspectorPanel / BatchPanel / ReviewPanel
tools/
  test.mjs              24 项内核断言
  e2e*.mjs              Playwright 端到端脚本(编辑-重算保留、批次流、放行闸门、撤销、快捷键)
```

## 已知边界

- 状态只存在内存里,刷新页面会丢失当前批次(素材包是导出的 ZIP,不依赖刷新)。
- 无后端:批次与复核是单机流程,没有多用户协商。
- 渲染按 DPR 上限 2.5 取像素密度;4096px 以上的视口只保证这一密度下的清晰度。
