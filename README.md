# 蚁筑 NESTWORKS · 地下蚁巢过程式场景平台

昆虫科普内容工作室的蚁巢场景制作与项目交付平台。制作员在三维视图里按参数出场景，主管审核退回并把关交付，客户在项目里下单。

技术栈：**Svelte 5**（runes）+ **Babylon.js 9** + Vite。数据存浏览器 localStorage，无需后端。

## 快速开始

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm test           # 生成引擎单测（确定性 / 锁定 / 参数边界）
npm run build      # 生产构建
```

若 5173 被占用，`npm run dev -- --port 5199`。

## 四个界面

| 界面 | 使用者 | 职责 |
| --- | --- | --- |
| **场景制作** | 制作员 / 主管 | 调参数生成蚁巢、拖控制点改甬道、切材质、剖切、切镜头、存镜头 |
| **镜头任务** | 制作员 / 主管 | 按项目汇总镜头，草稿 → 待审 → 后台退回/通过，显示返工次数与截止时间 |
| **审核交付** | 主管 | 核预览与参数；退回须写明要改的种子或甬道编号；通过后整包交付并导出 ZIP |
| **项目下单** | 客户 / 主管 | 浏览项目进度，下单生成镜头包 |

顶栏可切换身份；身份决定能进入哪些界面与可用操作（制作员不能审核，客户不能改场景）。

## 生成规则

参数五项：入口数量（1–6）、巢深（8–30 m）、主道分支角（20–75°）、分室层数（2–6）、通道管径（0.25–1.1 m）。

- **主甬道**：每个入口一条，从地表竖直下探至巢底，带种子决定的水平摆动。
- **分支**：每层在对应深度处从主甬道分叉，按分支角向外下斜，方位角按入口均分并加种子扰动。
- **末端分室**：每条甬道末端一个，按体积从大到小自动分型——最大的为 **育幼室**，中等为 **储粮室**，较小的为 **菌圃室**；每种形态用不同椭球比例（育幼偏球、储粮扁平、菌圃近似球）。
- 同层分室做确定性松弛，避免互相穿插并留在土块内。

所有随机数来自 `mulberry32(hash(seed + 用途标签))`，**同一 seed + 同一参数每次生成的结果逐字节一致**（有单测覆盖）。引擎不依赖 `Math.random`、`Date` 或 DOM。

## 锁定与重算

选中甬道后拖动亮色控制点即可改走向，松手即：

1. 该甬道按新控制点打上 **锁定** 标记（黄色，视口与列表双重标识）；
2. 只重算相连分室；
3. 其余甬道保持原样。

此后调参数点「重新生成场景」：**锁定甬道原样保留，其余全部重算**。锁定记录含控制点、半径、相连分室的中心/尺寸/类型，因此分室形态也一并冻结。参数变化导致某条锁定甬道在新布局中「不存在」时，它作为保留条目继续存在（右栏标注「保留自旧参数」）。解锁后恢复为按当前种子与参数生成的基线。

## 复现

- 种子可锁定、可复制；点「复现码」得到 `NEST1.…` 字符串，内含种子和全部参数，粘给同事即可还原完全一致的场景。
- 交付 ZIP 内每个镜头都带 `seed`、完整参数、`reproCode` 与锁定明细；导出时会逐个跑一遍生成校验并写进 `README.md` 与 `manifest.json`。

## 视角与镜头

- 相机：全景透视、俯视、剖切正视；剖切深度可调，剖切面始终朝向相机（环绕时自动换轴）。
- 材质：干土 / 湿土 / 砂砾，各有独立程序化贴图与粗糙度；方向光方位可调。
- 视图模式：实体 / 透视 / X 光。
- 「保存镜头」写入种子、参数、锁定、材质、剖切与当前相机姿态，并截取一张预览图；在镜头任务里点开即还原同一视角。

