# 小天体体素建模工作台

为小行星探测任务概念设计服务的体素建模与项目制交付系统。
原生 TypeScript + Web Components + WebGPU,无前端框架。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建(dist/)
npm run preview    # 预览生产构建
```

需要支持 WebGPU 的浏览器(Chrome / Edge 113+)。

## 四个界面

| 界面 | 路由 | 说明 |
|---|---|---|
| 项目列表 / 下单 | `#/projects` | 客户下单建项目(名称、需求、体素上限、目标面数、网格规格、截止时间) |
| 项目详情 | `#/project/:id` | 按镜头拆分任务、分配制作员、提交审核、查看状态与审核意见 |
| 体素建模工作台 | `#/editor/:shotId` | 三维网格体素建模(核心编辑器) |
| 审核与交付 | `#/review/:id` | 主管逐镜头通过/退回(必填问题说明)、返工计数、打包交付 ZIP |

右上角切换角色(客户 / 制作员 / 主管)与姓名,数据保存在 localStorage。

## 建模功能

- **按层堆体素**:Z 层切片滑杆,显示模式:全部 / 当前层及以下 / 仅当前层;可开启"仅编辑当前 Z 层"
- **左右镜像对称**:X 轴镜像开关,所有编辑(含笔刷、框选粘贴)同步生成另一侧,画布中显示镜像面
- **框选**:框选工具点两个角点 → 复制 / 粘贴 / 沿 XYZ 任意轴平移(ΔX ΔY ΔZ)/ 删除选区
- **三种笔刷**(半径、强度、随机种子可调):
  - 球化:填充球体塑形;Alt+点击挖球形陨石坑
  - 压平:把半径内表面压平到点击高度(着陆区/台地)
  - 随机凹凸:确定性噪声侵蚀/堆积表面,塑造陨石坑缘与碎石堆
- **实时统计**:体素总量 / 上限(超限红色警告横幅)、包围盒尺寸、当前层体素数、网格面数
- **导出**:合并网格(面剔除)→ 顶点聚类减面到目标面数 → 导出 OBJ
- 撤销(Ctrl+Z,30 步)、自动保存

## 交互

左键编辑(拖动连续)| 右键拖动旋转 | 中键平移 | 滚轮缩放 | Esc 取消选区

## 交付流程

客户下单 → 拆分镜头分配给制作员 → 制作员建模并提交审核 → 主管审核:
退回(必填问题,返工次数 +1)或通过 → 全部通过后打包交付
(各镜头减面 OBJ + 交付清单 JSON 的 ZIP),记录返工次数与截止时间,逾期高亮。
